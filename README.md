## 💡 O que é o Materialize CSS?

O **Materialize CSS** é um framework front-end criado com base nas diretrizes do [Material Design](https://material.io/) do Google. Ele oferece:

- Sistema de **grid responsivo** de 12 colunas
- Componentes prontos: cards, modais, navbar, forms, etc.
- **Animações e efeitos** como o `waves-effect`
- Paleta de **cores completa** via classes utilitárias
- Integração nativa com **Material Icons**
